# L0—L4 分层上下文读取

## 目的

长篇小说不应每次加载全部正文。分层读取既节省上下文，也防止重要规则被无关文字淹没、角色提前知道未来，以及只读摘要造成声音和情感失真。

## L0：当前任务

记录本次要做什么、允许改什么、禁止改什么、交付状态、作者明确要求、当前正式状态版本和草稿分支。L0决定工作边界，不能因读取更多资料而扩大任务。

## L1：硬性事实

只加载本次任务不能违反的内容：用户最新要求、正式设定、力量或规则体系、角色当前状态、任务契约，以及四表中相关的时间、道具、术语和数字。

不要机械加载整套设定。先搜索任务涉及的人物、能力、地点、资源和事件，再读取命中的正式上下文。

## L2：近场完整原文

读取当前章节、相邻章节和与当前场景直接相关的关键原文。涉及对白节奏、心理、暧昧、身体细节、战斗动作、关键伏笔或人物初次出场时，必须读取原文，不能以摘要替代。

整章或影响承接的修改读取前章结尾及已存在的后章承接；错字和局部措辞修改只读足够判断的邻近段落。未来正文默认不读，除非已有连续性依赖需要核对。

## L3：远场结构记忆

读取章节摘要、角色经历、关系变化、卷纲、时间线切片、伏笔、未解决任务和相关历史事件。摘要不足以支持判断时，定向返回对应正式原文核实，不直接加载全书。

## L4：冷区

明确本次暂不加载的内容：无关人物、未来剧情、未采用方案、历史废案、无关城市与规则、当前角色不知道的秘密。冷区不删除，只是不占用本次上下文。

## 主 Agent与角色 Agent

主 Agent可以拥有作者层面的完整信息，但不能把作者知识泄露给角色。角色 Agent只获得该角色可访问的 L0—L3：角色卡、个人经历、亲历原文、当前可知事实和合理误解；其他人物秘密、幕后真相和未来大纲进入该角色的 L4。

角色 Agent 的 L0 注明 formal_version 与 draft_branch；草稿假定与正式事实分开。版本向前推进时按角色系统发送确认增量，不兼容分支的内容互为 L4，不能混用。

## 读取停止条件

默认从当前任务、相关规则、角色现状、前章收尾、直接相关历史场景开始。长期经历使用带出处的摘要，直接影响本场声音、选择或情感的经历再读原文。事实与本次选择已有依据时停止读取；只因具体缺口、矛盾或本场未见过的能力用法继续检索，不为抽象的“更全面”反复扫描。

同一上下文中已读且未变化的规则和资料切片复用。跨会话或发生变化时定向更新，不假设存在不可见的永久记忆。隐藏 L0—L4 是信息筛选方式，不要求每章生成五份文档或列出全部冷区资料。

## 各任务读取重点

- 讨论剧情：L0、相关L1、人物L3；必要时读取关键L2。
- 写大纲：L0、正式L1、角色L3、相关卷章L2。
- 写草稿：完整执行L0—L4，重视L2。
- 修改章节：目标与相邻L2优先，再补相关L1和L3。
- 阶段审查：读取该剧情段全文或逐章核心原文、对应L1、四表和段前段后状态。

默认不向作者展示上下文包，除非作者要求核对。
