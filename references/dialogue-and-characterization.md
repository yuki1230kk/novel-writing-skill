# 人物塑造与自然对白

## 核心原则

对白不是几句独立“关键台词”的拼接，而是人物在具体关系、情绪和压力下对上一句话作出的局部反应。

真人通常不会一次说清结论、理由、态度和底线，也不会准确复述自己的心理。人物可以只听见最刺耳的一个词、误解对方、回避重点、答非所问、改口、被打断或用行动代替回答。自然不等于随意添加“呃、嗯”和网络口头禅；正式、古老或高位角色也应回应现场的人，而不是替作者总结局势。

## 先判断谈话类型

写作前判断当前主要属于哪类交流：

- 日常：允许跑题、共同语境、省略和没有剧情信息的小反应，但整段仍需推动关系、状态或生活感。
- 办事：信息直接，却不互相背诵双方都知道的常识。
- 争吵：人会抓住伤人的词、翻旧账、拒绝回答或重复自己的核心诉求。
- 暧昧或亲密：真正重要的话往往说不完整，动作、沉默和错误理解承担更多内容。
- 谈判或审讯：双方隐藏目的、试探、装傻、压价和故意误解，不主动交代完整底牌。
- 正式上下级交流：身份决定谁能打断、谁必须解释、谁可以沉默，但仍要有即时反应。

一场谈话可以转类，例如日常逐渐变成争吵；转变必须由一句话、一个动作或新信息触发。

## 规划阶段：只做交流意图，不写金句

角色 Agent 在规划阶段只提供：

- 他想让对方做什么。
- 他真正想说却不会直接说什么。
- 他准备回避哪个问题。
- 他最容易被哪句话刺中。
- 他会装成什么态度。
- 什么情况下会说漏嘴、改口、沉默或离开。
- 他的措辞方向、关系距离和绝不会使用的表达。

规划阶段不要求角色 Agent 提供三至五句“关键台词”，主 Agent 也不得直接拼接多个 Agent 的示例句构成对话。

## 逐句反应链

主 Agent 先明确交流意图，再按实际轮次写作。重要交锋可用以下问题判断自然反应，不要求每句生成检查表：

1. 说话者实际听见并在意了上一句的哪一部分？
2. 他理解正确、误解，还是故意曲解？
3. 这句话先引发什么身体或情绪反应？
4. 他愿不愿正面回答？
5. 他最终只说出口多少？

对话整体应有自然的回应关系；允许主动换话题、打断、延迟回答和借题发挥，只要源于现场目的或情绪。若台词只在回应作者大纲而无人物动因，应删掉或改写。

同一个信息不要由两个人轮流解释。允许一轮谈话暂时没有得到答案，让答案从后续选择、动作或代价中出现。

## 共享语境与不完整表达

熟人会省略共同知道的人名、前因和规则，使用“那件事”“还是老地方”“你又来”之类依赖语境的表达。陌生人才需要更多确认和解释。

人物不必每次主谓宾完整，也不必把逻辑关系全部说出。可以有停顿、重复、半句收回和被打断，但每次不完整都要来自紧张、隐瞒、关系或现场变化，不能随机撒语气词制造“口语感”。

一段交流整体需要推进，单句不必句句承载新设定。普通人很少在一句话里同时完成结论、理由、心理诊断、边界声明和行动方案。

## 人物声音与关系变体

为 S、A、B 类角色维护对白档案，记录：

- 平常句长、词汇、礼貌程度、是否反问或绕弯。
- 紧张、生气、心虚、求人、撒谎时怎样变化。
- 面对上级、陌生人、朋友、敌人和亲密对象时的不同说法。
- 常用的回避方式、沉默方式和情绪泄漏动作。
- 绝不会使用的词、句式与心理分析口吻。
- 作者已经认可并归为正文的对白样本及其场景。

使用 assets/project-state-templates/character-dialogue-profile.md。草稿台词不得进入正式样本库；剧情段深度同步时，才从已确认章节中按需选取少量代表性台词，注明对象、情绪和场景。快速正式化不整理对白档案。对白样本仅供参考，不在新章节机械复读。

## 动作、停顿与空间

动作应泄露未说出口的东西、改变互动距离或打断谈话。不要为每句台词机械添加挑眉、轻笑、眯眼和目光微动。

沉默也必须有人承受：谁先移开视线、谁继续手里的事、谁误以为对方默认、谁被迫再次开口。不要只写“空气陷入沉默”后直接进入下一段。

## 高风险 AI 句式

下列结构不是绝对禁止，但普通角色频繁使用时应重点重写：

- “你真正想要的不是……而是……”
- “这取决于……”
- “我理解你的感受，但……”
- “如果我没有猜错，你之所以……”
- “所以你的意思是……”
- “我们现在面临几个问题……”
- “我可以答应，不过条件是……”

这些句式容易让人物像心理咨询师、辩论者或作者代言人。保留时必须符合角色职业、教养、关系和当前策略。

## 对白完成后的角色复核

按角色系统统一调度，仅在成稿出现具体人物失真或重大未决选择时追加针对性复核。提供相关片段，每个角色只审查自己的台词：

- 我真的会在此刻说这句话吗？
- 我是不是说得过于完整、聪明或坦白？
- 我会先回应对方的哪一个词？
- 哪句应该删掉、缩短、回避或换成动作？
- 是否泄露了我不知道或决定隐瞒的信息？

角色 Agent 只提出本角色台词的最小修改，不重写其他角色，也不接管整场结构。主 Agent 最终统一节奏。

普通日常或功能性短对白可由主 Agent 依据正式对白档案自行检查，不必每次额外调用 Agent。

## 人话检查

本节是详细人话检查的唯一标准。主 Agent自检和读者冷读各按自身职责使用，其他文件引用不增加检查轮数。完稿后检查重要交流：

- 这句话是在回应上一句，还是在回应整份大纲？
- 人物是否说出了只有作者才会总结的心理和主题？
- 双方是否重复彼此已经知道的设定？
- 是否把结论、理由、态度和底线一次全说完？
- 是否每个人都过分冷静、准确、简洁和擅长分析别人？
- 去掉解释性对白后，动作和上下文能否承担信息？
- 现实中一口气念出来是否拗口、书面或尴尬？
- 一整段是否只有语言交换，没有动作、误读、关系变化或现场干扰？

暂时遮住人物名字与提示语，只看台词；若台词能够随意互换，依据对白档案重写。再朗读关键对话，优先修正现实中难以顺口说出的句子。

不要为了“像真人”故意制造病句、方言、脏话或大量口头禅。目标是人物在当下会自然说出的话，而不是统一的口语化表面。

允许符合人物的完整长句、明确情绪、幽默和有意的旁白；清楚直接并不等于 AI 味。对句式的判断以具体作用为准，不机械禁词，不为缩短文字删掉必要的生活感、气氛与细腻情感。
