# 起点与番茄男频商业网文标准

## 核心检查

- 主角是否主动提出目标、采取行动并承担结果。
- 阶段目标是否清楚，读者是否知道近期在期待什么。
- 每章是否有推进，连续过渡章是否应合并。
- 爽点是否经过铺垫并得到足量兑现。
- 主角的收益是否可感知：实力、资源、信息、身份、关系或精神成长。
- 压抑是否有期限和反馈，是否长期只吃亏。
- 反派是否拥有合理目标、情报和应对，而非配合主角装逼。
- 重要角色出场后是否及时发挥作用。
- 章末是否具有追读动力。

## 主角装逼

有效装逼来自认知差、准备、规则利用、能力组合、勇气、承担代价或此前积累。先让读者理解困难，再让主角完成别人做不到的事。

禁止依靠：敌人突然忘记能力、旁观者机械震惊、临时新增金手指、没有代价的越级、作者强行宣布主角聪明。

## 爽点与代价

爽点兑现后允许保留更大麻烦，但不能用新麻烦立刻抹掉全部成果。主角付出的代价必须换回他重视的东西；无意义受苦不等于深度。

## 信息投放

优先让规则在解决问题时被看见。一次只解释当前决策所需的信息，避免人物为了读者互相背诵常识。

## 毒点预警

重点检查：主角无底线吃亏、强行误会、关键时刻不沟通、女角色工具化、反派反复放走、战利品无理由丢失、实力忽高忽低、配角抢走高潮、主角长期没有主观目标、承诺的爽点迟迟不兑现。
